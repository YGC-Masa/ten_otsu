# v039_110 差分メモ

## 目的
v039_109 実機確認で出た以下の問題を修正する。

- 右メニューの「回想」を「回想アルバム」にしたい
- 回想/外回りで再生ボタンが押せない、または押せる状態が分かりづらい
- 季節変更は巡回ボタンだけでなく、春夏秋冬を直接押したい
- メンバー画面で親愛ストーリー枠がプロフィール内に入り、レイアウトが崩れている
- 親愛ストーリー枠は既存プロフィール右側の独立エリアに新設したい

## 主な変更

### 1. 回想アルバム改名
右メニュー表示を「回想」から「回想アルバム」に変更。
storyMenu 内タイトルとメッセージも回想アルバム表記に統一。

### 2. 外回りの開始ボタン改善
外回りで候補ストーリーがある場合、気配確認前でも開始ボタンを押せるようにした。
読了済みしかない場合でも、開発用 `TENOTSU_DEBUG_ALL_STORIES = true` の間は「再会テスト」として再生できる。

### 3. 春夏秋冬の直接選択
外回り上部に春夏秋冬のボタンを表示し、直接季節を変更できるようにした。
従来の「季節を変える」巡回ボタンも残している。

### 4. メンバー画面レイアウト分離
親愛ストーリー枠をメンバープロフィール内部から外し、右側の独立エリア `tenotsu-member-story-side` に移動。
これにより、プロフィール表示とストーリー選択枠が干渉しない。

## 確認ポイント

1. 右メニューが「回想アルバム」になっている
2. 回想アルバムでカード右上に「再生」が見える
3. 外回りで春夏秋冬ボタンを直接押せる
4. 夏を選ぶとマリンピアの場所が選べる
5. 候補がある場合、エンカウント開始または再会テストボタンが押せる
6. メンバー画面で親愛ストーリー枠がプロフィール右側の独立枠に出る
