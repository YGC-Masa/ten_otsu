## 修正内容

### ゲーム側：人物ロード・フェード共通処理を実装
シナリオファイルには手を入れず、ゲーム側で `storySprites` / `characters` / `clearStorySprites` を検知して共通処理します。

人物変更時の流れ：

1. テキスト進行受付停止
2. 次に表示する人物画像をプリロード
3. 現在表示中の人物をフェードアウトして完了待ち
4. ステップ本体処理を実行
5. 新しい人物を非表示状態で配置
6. 人物フェードイン完了待ち
7. テキスト進行受付再開

補足：

- 非表示が必要な場合はフェードアウト完了まで待ちます
- アンロード / DOM削除は待たず、ステップ本体処理側で自然に差し替えます
- 同じ人物・同じ立ち絵が継続する場合は演出を挟みません
