# ten_otsu v039_77 差分

## 概要

v039_76 から v039_77 では、右メニューと新規「チューニング」入口を追加しました。

- 右メニューの「メインメニュー」表示を削除
- 「外回り」と「ショップ」の間に「チューニング」を追加
- チューニング画面を新設し、テックラボつくもへの入口として表示
- チューニング内に「店舗メニュー」カテゴリを追加
  - 事務所
  - 店舗
  - 店長

## 主な変更

### 右メニュー整理

右メニュー上部の「メインメニュー」見出しを表示しないようにし、メニューの縦幅を少し圧縮しました。

### チューニング入口

チューニングは、つくもでメンバーや店長のギアを強化するための入口です。
今回は強化データ本体はまだ接続せず、画面・カテゴリ・導線を先に用意しています。

### 店舗メニュー

チューニング画面内に以下の3カテゴリを用意しました。

```text
店舗メニュー
├ 事務所
├ 店舗
└ 店長
```
