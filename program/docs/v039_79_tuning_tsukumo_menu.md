# v039_79 チューニング画面 / テックラボつくも店内背景

## 目的

チューニングメニューを復活し、テックラボつくもへの入口として使用する。
背景にはつくも店内画像を採用し、装備・設備強化へ進む画面として見せる。

## 画面構成

```text
チューニング
├ メンバー装備強化
├ 店長装備強化
├ 店舗設備強化
└ 事務所に戻る
```

## UI方針

- 背景は `images/assets/bgev/bg_tsukumo_tuning.png`
- 左〜中央寄りに半透明の操作カードを配置
- 右メニューと重ならないよう、右側余白を確保
- ボタンは木目・工房・緑系の雰囲気に合わせた配色
- 強化実行は後続接続。今回は閲覧と導線を固定

## 後続接続候補

- メンバー装備強化：各メンバーのステータス補正、CT短縮、必殺ゲージ補正
- 店長装備強化：店長HELP、指示力、妨害耐性
- 店舗設備強化：売上補正、ラッシュ補助、金貨回収効率
