# v039_36 ストーリーサーフェス目視デバッグ

## 目的

通常の見た目ではなく、黒フラッシュと立ち絵非表示の原因を目視で特定するためのデバッグ版。

## 追加内容

- z-index 500 / 1000 / 2000 / 3000 / 4000 / 6000 にキャラ立ち絵プローブを配置。
- 雪乃、緋奈、藍、翠、こがね、琥珀を左から横並びに表示。
- クリック直後、applyStoryStep前後、背景切替前後、テキスト更新前にデバッグラベルを一瞬表示。
- fade layer が visible になった場合、赤い `FADE VISIBLE` 警告ラベルを表示。

## 見方

- どのz-index帯まで見えるかを確認する。
- 黒フラッシュ直前に左上へ出るラベルを見る。
- `FADE VISIBLE` が出る場合はfade layerが原因。
- ラベルなしで黒くなる場合は背景差し替え/背景レイヤー側が原因。
