# v039_84 event battle input rework

## 目的

v039_83で実装したイベントバトルを、通常モードとラッシュモードの役割がより明確になるよう調整した。

## 通常モード

通常モードでは、ブラック家電星人のノイズシールドを削る。

### TAP

画面上に2〜3個の青い小サークルが表示される。
大きな水色リングが外側から縮小し、小サークルと重なった瞬間に押すとJUST。

### FLICK

画面上に緑の矢印が表示される。
矢印方向へフリックするとJUST。

### HOLD

画面左右にピンクの左右矢印が出現する。
両方をホールドすると中央がビリビリエフェクトで接続される。
充電完了後、左右を同時に外側へフリックするとJUST。

## ラッシュモード

シールド0後に、すぐノーツへ入らず「これよりラッシュモード」演出と3カウントを挟む。

- 3 → 2 → 1 → GO
- ノーツ速度をv039_83より遅く調整
- 最後のノーツおよびゴーストノーツが画面外へ抜ける余韻まで終了しない

## リズム解釈

これは8拍子ではなく、4/4の8ビート基準。
ハイハットの「チッ、チッ、チッ」は裏で流れる基本リズム。
プレイヤーはKICK / SNARE / HIGH TOM / LOW TOM / CRASHのフィルインを入力する。
