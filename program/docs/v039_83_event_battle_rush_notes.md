# v039_83 イベントバトル・5レーンラッシュノーツ実装

## 目的

v039_82で用意したラッシュパターンテーブルを、実際に遊べる5レーンノーツ落下へ接続する。
また、横画面で縦長になりやすいイベントバトル結果画面をスクロール対応にする。

## 通常モード

- TAP / FLICK / HOLD でブラック家電星人のノイズシールドを削る。
- シールドが0になると、即リザルトではなくRUSH MODEへ移行する。

## RUSH MODE

5レーン構成。

```text
KICK / SNARE / HIGH TOM / LOW TOM / CRASH
```

- 前半リズム7種からランダム選択。
- 後半フィル4種からランダム選択。
- 合成されたラッシュパターンのノーツを上から落下表示する。
- 判定ライン付近で対応レーンを叩く。

## 判定

```text
JUST: ±105ms
GOOD: ±230ms
MISS: 上記外、または空振り
```

## ハイハット/ゴースト

「ツ」は HAT_GHOST として扱う。
画面上には薄く表示するが、操作対象ではない。
将来的には裏拍ガイドやSE演出に接続する。

## 結果画面

- 横画面で縦に長くなりやすいため、結果パネルを縦スクロール対応に変更。
- ボス情報欄を結果時だけ圧縮し、下段リザルトを広く使う。

## 報酬補正

- RUSH JUST / GOOD / MISS を記録。
- FULL COMBO でイベントメダル補正。
- ALL JUST でチューニング素材補正。
- コンボ数とパターン倍率でスコアが伸びる。
