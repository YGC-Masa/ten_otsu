# v039_86 イベントバトル入力・4レーン調整

## 目的

イベントバトルの通常モードとラッシュフィルインを、横画面で見やすく・押しやすくする。

## 変更

- 通常モードの入力表示をブラック家電星人より前面へ出す。
- HOLDを廃止し、ピンクのDOUBLE TAPターゲットに置き換える。
- FLICK矢印を緑から黄色へ変更する。
- ラッシュフィルインを4レーン化する。
  - KICK
  - SNARE
  - TOM
  - CRASH
- HIGH TOM / LOW TOM は TOM レーンに統合する。
- ラッシュモード表示と3カウントを廃止し、シールド0から直接フィルインを開始する。
- ノーツ飛来速度を上げ、画面上から下までレーンとして使う。

## 備考

ハイハット/ツは引き続きゴーストノーツとして扱い、操作対象にはしない。
