# v039_63 battle end declaration

## 目的
バトルリザルト表示直後のボタンがゲーム中UIや右メニューと重なり、連打時に意図しないメニュー遷移が発生する問題を軽減する。

## 対応
- 営業終了時に約3秒間、大きな「営業終了」宣言画面を表示。
- 宣言中はリザルトボタンを出さず、クリックを吸収する専用オーバーレイを表示。
- 3秒後に営業結果リザルトを表示。
- バトル内ボタンクリックで `preventDefault` / `stopPropagation` を行い、外側UIへのイベント伝播を抑制。

## 表示順
1. 営業終了
2. 3秒の終了宣言
3. 営業結果リザルト
