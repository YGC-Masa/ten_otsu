# v039_80 ST/BP 自動回復設定

## 変更内容

- スタミナを 6分に1 自動回復するように変更。
- バトルPを 60分に1 自動回復するように変更。
- オフライン中の経過時間も、次回読み込み時にまとめて反映。
- 上限到達時はそれ以上回復しない。
- ST/BP HUD と店舗営業のリソース表示に、次回回復までの目安を表示。

## 回復仕様

```text
スタミナ: 最大100 / 6分に1回復
バトルP: 最大3 / 60分に1回復
```

## 保存キー

```text
tenotsu_stamina_v1
tenotsu_battle_point_v1
```

## 互換性

v039_79以前の `updatedAt` を初回の回復基準時刻として利用します。新形式では `recoveryAnchorAt` を持ち、消費後・全回復後・自動回復後に更新します。
