# v039_72 rival cutin / help / rush adjustment

## 概要

ビリビリバトルの演出とUI配置を調整する。

## 変更点

### 必殺技カットイン

これまでカットインは画面全体に近い範囲で表示され、ひだまりメンバー枠に被ることがあった。

v039_72ではカットイン表示範囲を敵枠エリア内に制限し、メンバー操作を妨げにくくした。

### 店長HELP

店長HELPボタンを通常バトルと同じく、メンバー枠の直上に配置する。

### ラッシュタイム

通常バトルのタイムセールに相当する演出として、ビリビリバトルにラッシュタイムを追加。

- 発動条件：残り18秒以下
- 通常時最大出現数：4体
- ラッシュ時最大出現数：6体
- 発動時に「ラッシュタイム！」演出を表示
- HUDにラッシュ状態を表示

## 今後の調整候補

- ラッシュタイム中のスコア倍率
- ラッシュタイム専用BGM/SE
- ビリビリ側CPUの行動頻度調整
- ラッシュ中限定の家電星人特性
