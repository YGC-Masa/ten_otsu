# v039_76 VSビリビリ調整・採用画像反映

## 目的

v039_75で強くしたビリビリ側CPUを、プレイ感に合わせて約10%だけ弱めます。
また、小春・真冬・なつのカード画像とカットイン画像を、ひだまりメンバーと近いサイズ感の採用版に差し替えます。

## 調整

- RIVAL_POWER_MULTIPLIER = 0.90 を追加
- ビリビリ側スコア獲得に倍率を適用
- ビリビリ側必殺ゲージ増加に倍率を適用
- ビリビリ側通常行動の成功確率に倍率を適用
- 横取り確率の下限/上限を 0.28〜0.72 に調整
