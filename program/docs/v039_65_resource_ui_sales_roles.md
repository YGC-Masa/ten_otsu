# v039_65 resource UI / sales role split

## 目的

v039_64で追加したスタミナHUDと店舗営業メニューを、実際のプレイ導線に合わせて整理する。

## 修正内容

- スタミナHUDを左上から右上へ移動。
- VSビリビリ用に通常スタミナとは別の `Battle Point / BP` 基盤を追加。
- 店舗営業メニューのリソース表示を、通常・イベントは `ST`、バトル営業は `BP` に分離。
- 右メインメニューの横幅を少し縮小し、テキストエリア右余白をメニュー幅に合わせて再計算。
- 通常営業・バトル営業・イベント営業の報酬役割をデータとして明示。

## 営業種別の役割案

| 種別 | 消費 | 主な役割 |
|---|---:|---|
| 通常営業 | ST 10 | 経験値 / 売上 / 基礎報酬の安定周回 |
| バトル営業 | BP 1 | VSビリビリ。ライバル報酬 / 交換素材 / 称号系 |
| イベント営業 | ST 20 | イベント報酬 / 限定素材 / 思い出解禁。将来的にドラムリズムボス戦 |

## 補足

BPは現時点では最大5、初期5。回復時間や配布タイミングは未実装。将来、日次回復・チケット配布・イベント報酬と接続する想定。
