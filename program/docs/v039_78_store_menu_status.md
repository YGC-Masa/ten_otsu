# v039_78 店舗メニュー閲覧管理

## 目的

v039_77で追加した「チューニング」入口を廃止し、右メニューの「店舗」から、店舗系の閲覧管理へ入る構造へ整理する。

## 仕様

右メニューの「店舗」を押すと、店舗メニューを表示する。

```text
店舗
├ 事務所 → 事務所モードへ戻る
├ 店舗   → 店舗ステータスを表示
└ 店長   → 店長ステータスを表示
```

現時点では強化実行ではなく、閲覧管理のみ。
メンバーや店長のギア強化、素材消費、テックラボつくも連携は後続で別途接続する。

## 変更点

- 右メニューから「チューニング」を削除
- 右メニューの「店舗」を `storeStatus` に接続
- `program/v039/storeStatus.js` を追加
- `program/v039/tuning.js` は削除対象
- 店舗ステータス、店長ステータスの仮表示を追加
- 事務所ボタンは事務所モードへ戻る

## 備考

このバージョンでは、店舗・店長ステータスは仮値表示。実ステータス、装備、強化段階、素材消費は後続版で接続する。
