# v039_81 イベントバトル入口と通常モード

## 目的

イベント営業を通常バトル仮接続から切り離し、ブラック家電星人ボス戦の入口を作る。
本バージョンではラッシュモードとフィルインノーツ本実装は行わず、通常モードのみ実装する。

## 通常モード

- ブラック家電星人のHP / SHIELD / NOISEを表示する。
- プレイヤーはタップ・フリック・ホールドでノイズシールドを削る。
- SHIELDが0になると撃破仮リザルトへ遷移する。

## 入力

- TAP：基本シールド削り。
- FLICK：指定方向にノイズを流す。成功時は大きく削る。
- HOLD：長押し調律。長さが合うと大きく削る。

## 将来のフィルインノーツ

ラッシュモード用に複数のフィルインパターンをテーブル化した。
後続バージョンでは登録パターンを増やし、その中からランダムに選択してノーツ列を生成する。

初期候補：

- ドン、タン、ドン、タン、タカ、トン、ジャーン
- ドン、ドン、タン、タカ、トン、ジャーン
- ドン、タン、タカ、ドン、タン、トン、ジャーン
- タン、ドン、タカ、トン、ドン、ジャーン
