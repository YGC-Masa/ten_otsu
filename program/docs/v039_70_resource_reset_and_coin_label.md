# v039_70 resource reset and appliance coin label

## 目的

- 設定画面から検証用にスタミナとバトルPを最大値へ戻せるようにする。
- 家電星人の都市鉱山由来の排出物表記を、money と gold の混同が起きやすい「金」から「金貨」へ統一する。

## 変更点

- 設定画面に以下のボタンを追加。
  - ST/BPを最大値へリセット
  - スタミナだけリセット
  - バトルPだけリセット
- リセット時に HUD も即時更新。
- ビリビリバトル報酬表記を「家電星人金貨」へ変更。
- 報酬保存データは `applianceCoins` を使用。旧 `applianceGold` が残っている場合は初回読込時に移行する。

## 確認項目

- 設定画面にST/BPリセットボタンが表示される。
- スタミナを消費した状態でボタンを押すと 100/100 に戻る。
- バトルPを消費した状態でボタンを押すと 3/3 に戻る。
- ビリビリバトルの開始画面・結果画面で「家電星人金貨」と表示される。
