# v039_92 イベントバトル：メンバー5人表示・ローリングスワイプ修正

## 目的

v039_91では、ひだまりメンバー欄を横スクロール方式にしたものの、環境によってスワイプ操作が効かず、13人のループ表示を確認しにくい問題があった。

v039_92では、ネイティブスクロール依存をやめ、ファーストビュー5人固定のローリング表示に変更した。

## 仕様

- ひだまりメンバーは全13人を保持。
- 表示は常に5人。
- 左右スワイプで表示開始位置を1人ずつ移動。
- 13人目の次は1人目へ戻る。
- 1人目の前は13人目へ戻る。
- 左右ボタンでも同じ切り替えを実行可能。

## UI

```text
[‹] [メンバー1] [メンバー2] [メンバー3] [メンバー4] [メンバー5] [›]
```

ヘッダーには以下を表示する。

```text
ひだまりメンバー / 総合清掃力 / 即応 / 特攻 / ○番目から5人 / 全13人
```

## 入力事故対策

スワイプ時にメンバークリックが発火しないよう、一定時間クリックを抑止する。
