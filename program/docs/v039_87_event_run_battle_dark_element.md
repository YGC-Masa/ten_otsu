# v039_87 イベントバトル：ラン＆バトル方式 / ダークエレメント

## 方針変更

v039_86までのドラムフィルイン型リズムゲームは、処理負荷と操作複雑度を考慮して採用しない。
イベントバトルは、STでエンカウントし、専用イベントBPでブラック家電星人を追い返すラン＆バトル方式へ変更する。

## 新ルール

- イベント営業開始時にスタミナを消費して探索へ入る。
- ブラック家電星人にエンカウントする。
- 戦闘には専用イベントBPを1消費する。
- イベントBPは30分に1回復する。
- ブラック家電星人は撃退回数に応じてだんだん強くなる。
- 最初の数戦は倒しやすい。
- 戦うとクリスタル型のダークエレメントを得られる。
- ダークエレメントはイベントポイントとして扱う。
- 累計取得数ラダーに応じて戦利品を交換できる。

## 世界観

ダークエレメントは、ブラック家電星人の黒いノイズが結晶化したもの。
朔夜は夜間交換カウンターでこれを回収し、何かの調律や研究に利用している。

## 実装

- `program/v039/eventBattlePoint.js` を追加。
- `program/v039/eventBattle.js` をラン＆バトル方式に差し替え。
- `program/v039/eventBattle.css` をラン＆バトル用UIへ差し替え。
- `sales.js` のイベント営業を ST20のみ消費へ変更。
- 専用イベントBPはイベントバトル内の戦闘時に消費する。
