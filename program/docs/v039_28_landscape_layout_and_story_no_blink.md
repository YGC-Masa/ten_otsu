# v039_37 横画面レイアウト・ストーリー点滅抑制

## 修正点

- 横画面専用前提で、外回りイベント選択パネルの表示領域を再設計。
- 右6大メニューの幅をCSS変数で予約し、左イベントパネルが右メニューに潜り込まないようにした。
- Safari系の表示領域差異に強くするため `100dvh` / `100dvw` 前提の調整を追加。
- 外回りモードでは下部テキスト欄を完全非表示化。
- ストーリー中の背景/CG切替では黒フェード/opacity transitionを使わない。
- `setStoryLoading()` は入力ガードだけ行い、UI表示の点滅を抑える。

## 注意

スクショでは v039_26 表示だったため、v039_27未反映の可能性がある。
このv039_37は、v039_27のv038シナリオ復旧を含んだ状態からの差分。
