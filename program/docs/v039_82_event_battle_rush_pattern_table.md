# v039_82 イベントバトル・ラッシュパターンテーブル拡張

## 目的

イベントバトルのラッシュモード実装に向けて、ドラムフィルインの候補をデータ化する。

v039_82では実際のノーツ落下・判定はまだ行わず、ラッシュ突入予定時に使う候補パターンのランダム合成までを準備する。

## 前半リズム 7種

1. ドンタンドンタン
2. ドンタンドドタン
3. ドンタドドンタン
4. ドンタドドンタド
5. ドンタドツツタツ
6. ドンタンツドタン
7. ドンタドンドタン

## 後半フィルイン 4種

1. ドン、タン、ドン、タン、タカ、トン、ジャーン
2. ドン、ドン、タン、タカ、トン、ジャーン
3. ドン、タン、タカ、ドン、タン、トン、ジャーン
4. タン、ドン、タカ、トン、ドン、ジャーン

## 合成ルール

前半7種から1つ、後半4種から1つをランダムに選び、1つのラッシュパターンとして合成する。

組み合わせは 7 × 4 = 28通り。

## レーン

```text
KICK
SNARE
HIGH_TOM
LOW_TOM
CRASH
```

`ツ` はハイハット/ゴーストノートとして扱い、現段階では操作対象にしない。
将来的には裏拍ガイド・演出・スコア補正用に使う。

## v039_82の実装範囲

- パターンテーブルの追加。
- ランダム合成関数の追加。
- リザルト画面に選ばれた候補を表示。
- 入力ノーツ数、ゴースト数、スコア倍率を表示。
- 実プレイの5レーン落下ノーツは後続実装へ保留。
