# v039_51 story layer/text order fix

## 目的
ストーリー中に人物表示がテキストエリアより前面へ出る問題と、テキスト文字が黒くなって読めない問題を修正する。

## 修正
- `#tenotsu-story-body-sprite-layer` を `document.body` 直下ではなく `#tenotsu-app` 内へ移動
- 人物レイヤーをテキストUIの直前に挿入し、同一 stacking context に統一
- ストーリー中の表示順を固定
  - 背景 / イベントCG: z-index 100
  - 人物立ち絵: z-index 200
  - 既存テキストUI: z-index 300
  - 透明クリックレイヤー: z-index 400（視覚要素なし）
- ストーリー本文を白文字、話者名を `--speaker-color` または薄金色で強制
- `color: inherit` による黒文字化を上書き

## 確認項目
- 人物がテキストボックスの背面に表示される
- テキストエリアの本文が白文字で読める
- 話者名が薄金色/キャラ色で読める
- バトル実装 v039_49 と店舗営業メニュー整理 v039_50 は維持
