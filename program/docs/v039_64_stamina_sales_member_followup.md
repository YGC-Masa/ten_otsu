# v039_64 stamina / sales / member follow-up

## 目的
v039_63で安定したバトル終了導線の次段階として、営業に関係する情報を見えやすくし、次の実装分岐に備える。

## 変更内容

### スタミナUI
- 常時表示用の `tenotsu-stamina-hud` を追加。
- 現在ST / 最大ST / 簡易バーを表示。
- ストーリー中と起動中は非表示。
- 消費・回復時に自動更新。

### 店舗営業
- 営業メニュー上部に現在スタミナのサマリーを追加。
- 営業種別を以下の3つに整理。
  1. 通常営業
  2. バトル営業 / VSビリビリ
  3. イベント営業 / ボス戦予定
- 各営業に `battleType` を付与。
  - `normal`
  - `rival`
  - `eventBoss`
- イベント営業には将来用 `futureSystem: "drumRhythmBoss"` を付与。

### メンバー右詳細
- 持ち物1枠の見える化として「持ち物：なし」欄を追加。
- v039_56の `equipment.personal` と対応。
- 複数アイテムや装備UIは今後の拡張対象。

## 未実装・次候補
- スタミナ時間回復。
- 回復アイテム。
- バトル営業のVSビリビリ専用ルール。
- イベント営業のドラムリズムボス戦。
- 持ち物装備UI。
