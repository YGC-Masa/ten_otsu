# v039_74 sales start CTA compact layout

店舗営業画面の選択後詳細欄を見直し、開始ボタンをファーストビュー内に収めやすい位置へ移動した。

## UI方針

上部には既にスタミナ / バトルP の現在値表示があるため、選択モード詳細欄で大きなリソースバッジを再表示しない。

右側アクション枠に、消費内容が分かる開始ボタンを配置する。

## 開始ラベル

- 通常営業: ST10を消費して開始
- バトル営業 / VSビリビリ: ポイント1を消費して開始
- イベント営業: ST20 + BP1を消費して開始

## 挙動

詳細欄の開始ボタンを押すと、その場でリソースチェック・消費を行い、バトルへ遷移する。

従来の追加確認ダイアログは表示しない。
