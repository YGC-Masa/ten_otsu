# v039_75 ビリビリバトル強化・必殺可能演出・デッキ編成

## 目的

v039_74 のビリビリバトルを、実プレイ確認に合わせて調整する。

- ビリビリメンバーを少し強くする
- ひだまりメンバーの必殺技が使用可能なとき、通常バトル同様に枠を光らせる
- VSビリビリ開始前にデッキ編成できるようにする

## 変更内容

### ビリビリCPU強化

- 小春・真冬・なつの行動間隔を短縮
- CPUの横取り確率を上げる
- CPU側の必殺ゲージ増加速度を上げる
- CPU側の取得スコアに小さな補正を追加
- ラッシュ中はCPUの横取り確率も少し上がる

手動操作なら勝てる前提は維持しつつ、放置や雑な操作ではビリビリ側に押されやすくした。

### 必殺可能演出

ひだまりメンバーの必殺ゲージが100%かつCT待ちでない場合、メンバー枠に以下の演出を追加。

- 黄色寄りの発光枠
- キャラクター色による外枠グロー
- 必殺ゲージの発光
- 軽いパルスアニメーション

### デッキ編成

VSビリビリの開始画面・リザルト画面から「デッキ編成」を開けるようにした。

- 13人から5人を選択
- 通常バトルと同じ localStorage キー `tenotsu_battle_deck_v1` を利用
- 通常バトルとVSビリビリでデッキ設定を共有
- 決定後、次回バトル開始時にその5人で出撃
