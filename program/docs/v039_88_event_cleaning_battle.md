# v039_88 イベント清掃バトル設計

## 目的

v039_87のラン＆バトル方式を、世界観に合わせて「汚れた家電星人の清掃バトル」へ再設計した。
リズムゲーム要素は本線から外し、メンバーステータス・レベル・親愛度・属性相性でダメージを決める周回型イベントバトルにした。

## 世界観

家電星人は、メンテナンス不足で内部に汚れや不純物が溜まると悪の心が芽生える。
ひだまりメンバーが清掃バトルでメンテナンスすると、家電星人は正義の心を取り戻す。
その時に余計なエネルギーがクリスタル型の「ダークエレメント」として排出される。
ダークエレメントは朔夜が何かの調律に使っている。

## 基本フロー

1. イベント営業を選ぶ。
2. ST20でエンカウントする。
3. 6体の汚れた家電星人が出現する。
4. イベントBP1を消費して清掃バトルに入る。
5. 上段に家電星人6体、下段にひだまりメンバー5人を表示する。
6. メンバーで家電星人を清掃する。
7. 全員清掃するとダークエレメントを獲得する。

## 制限

- 逃走期限は12時間。
- メンバーのリキャストは30分。
- イベントBPは30分に1回復。
- 属性一致時は特攻。

## ダメージ

ダメージは以下を元に算出する。

- メンバーレベル
- 提案
- 根気
- 丁寧
- 誠実
- 親愛度
- 属性一致
- つくも準備品のバフ

## つくも準備品

売上金で購入できるバフアイテムを追加した。

- ひかるの洗浄剤：清掃ダメージ補正
- 陽里のクリーナークロス：リキャスト短縮
- 玄一郎の接点復活剤：属性一致特攻補正

## 報酬

清掃完了時、家電星人からダークエレメントを得る。
累計ダークエレメントは戦利品交換ラダーに使用する。
