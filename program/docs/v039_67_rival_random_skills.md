# v039_67 rival random skills

## 概要

ビリビリバトル用に、ビリビリ側の必殺技をレベル帯解禁＋ランダム使用できるテーブルとして拡張しました。

## 解禁レベル

- Lv1〜：既存の基本妨害・スコア補正
- Lv20〜：強めの妨害・取り合い要素
- Lv40〜：各キャラもう1種ずつ追加される上位行動

## 小春

- ビリビリ販促ラッシュ：ビリビリ側スコア倍率アップ
- うちらが最高やけん！：全員の必殺技ゲージ即時満タン
- 今だけビリビリ特価！：短時間のスコアバースト

## 真冬

- 冷静な価格比較：こちらのスコア倍率ダウン
- 少し休んだら如何ですか？：こちらの特定メンバーのリキャストキャンセル
- 勝率は計算済みです：こちらのコンボ倍率上昇を抑制

## なつ

- ほんわかヘルプスティール：店長HELPゲージを少し奪う
- みんな～、こっちがいいよ～：場の星人を魅了し、時間内に倒せないとビリビリ側スコア
- ちょっと休憩しよ～？：場の流れをゆるめつつ、迷い星人をビリビリ側に寄せる

## API

- `TenotsuApplianceAliens.getRivalSkillsForLevel(playerLevel, owner)`
- `TenotsuApplianceAliens.pickRandomRivalSkill(playerLevel, owner)`
- `TenotsuApplianceAliens.flattenRivalSkills()`
