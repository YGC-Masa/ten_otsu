# Expression Master

## 命名規則

```text
{キャラ文字}1{表情番号}{差分番号}.webp
```

例：

- `a10101.webp` = a1(緋奈) + 01(澄まし) + 01(1枚目)
- `b10501.webp` = b1(藍) + 05(笑顔) + 01(1枚目)
- `k10502.webp` = k1(彩愛) + 05(笑顔) + 02(2枚目)
- `k11002.webp` = k1(彩愛) + 10(軽い嫌悪) + 02(2枚目)

## 正規採用

- `k100102.webp` → `k11002.webp`
- `k40502.webp` → `k10502.webp`

## チャコール

- 正式ID: `ha`（旧実装ID `ch` は互換移行対象）
- キャラ文字: `n`
- 正式表情: `n10101.webp`〜`n12501.webp`
- 01 澄まし / 02 微笑み / 03 笑顔 / 04 怒り / 05 軽い嫌悪
- 06 悲しみ / 07 心配不安 / 08 動揺 / 09 驚き / 10 照れ
- 11 期待 / 12 得意げ / 13 いたずらな笑顔・舌出しウィンク
- 14 いたずらな笑顔・歯見せウィンク / 15 困り笑い / 16 真剣・決意
- 17 伏し目・余韻 / 18 拗ね・ぷいっ / 19 泣き笑い
- 20 無言の圧・見透かす / 21 黒い微笑み・不穏 / 22 ほっとした顔
- 23 見惚れ・ときめき前 / 24 眠そう・気だるげ / 25 照れ隠し怒り
