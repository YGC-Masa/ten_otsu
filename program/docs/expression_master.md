# Expression Master

## 命名規則

```text
{キャラ文字}1{表情番号}{差分番号}.webp
```

例：

- `a10101.webp` = a1(緋奈) + 01(澄まし) + 01(1枚目)
- `b10501.webp` = b1(藍) + 05(笑顔) + 01(1枚目)
- `k10502.webp` = k1(彩愛) + 05(笑顔) + 02(2枚目)
- `k11002.webp` = k1(彩愛) + 10(軽い嫌悪) + 02(2枚目)

## 正規採用

- `k100102.webp` → `k11002.webp`
- `k40502.webp` → `k10502.webp`
