# v039_62 メンバー右詳細レイアウト再整理

## 目的

メンバー名クリック後の右詳細で、Lv/EXP/6ステータス追加後に名前・キャッチコピー・コメントが狭い領域で混在し、表示が破綻する問題を修正する。

## 修正内容

- 右詳細上段を「立ち絵」＋「情報スタック」に再構成。
- 情報スタック内を以下の2ブロックに分離。
  - 名前エリア：名前、キャッチコピー、得意分野。
  - コメントエリア：ひとことコメント専用。
- 名前は横書き・1行省略表示を強制し、縦割れを防止。
- コメントは独立した高さを持つボックスに分け、名前欄を圧迫しない。
- Lv/EXP/6ステータスは従来通り下段ブロックとして維持。

## 表示構造

```text
[立ち絵] [名前/キャッチ/得意]
        [ひとことコメント]
[Lv / EXP / 6ステータス]
[将来拡張メモ]
```
