# v039_77 tuning menu entry

## 目的

右メニューに「チューニング」を追加し、テックラボつくもでメンバー・店長のギア強化へ進む入口を用意する。

## 変更点

- 右メニューの「メインメニュー」見出しを削除。
- 右メニューに「チューニング」を追加。
- 追加位置は「外回り」と「ショップ」の間。
- `program/v039/tuning.js` を追加。
- `layers.js` に `tuning` パネルと `showTuningPanel` / `hideTuningPanel` を追加。
- `state.js` のモード管理に `tuning` を追加。

## チューニング画面

チューニングは「テックラボつくも」への入口として扱う。
今後、メンバーや店長のギアのパワーアップを接続する。

## 店舗メニュー

```text
店舗メニュー
├ 事務所
├ 店舗
└ 店長
```

現時点では各カテゴリの説明表示まで接続し、実際の素材消費・強化処理は後続バージョンで追加する。
