## 目的

店長から提供された会話を基準に、閉店後の事務所でココアを飲む日常から、夜空が自分の言葉で店長への「好き」を伝えるまでの距離感を確認する。

25表情を機械的に一巡する既存の `yozora_expression_25_test` とは別シナリオ。こちらは会話の連続性と表情の意味対応を見るためのライブ寄りテストとする。

## 確認軸

- 夜空の一人称は「ぼく」、店長への呼びかけはこの会話原文に合わせて「店長」
- 静かさ、拗ね、照れ、決意、自発的接近が一続きの夜空として見えること
- 店長が逃げかける場面でも、夜空本人が原会話で示した「逃げないで」「ここで、言って」を保持すること
- 美空・緋奈への言及は比較による自己否定で終わらせず、「夜空のまま見つけてもらえる」着地点へ接続すること
- 原会話にある夜空本人の意思や好意を、外側の都合で弱めたり別の拒否へ置換しないこと
- 表情画像は採用済み25表情セットから場面に合うものだけを使用する
