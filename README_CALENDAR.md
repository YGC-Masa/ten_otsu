# 実日時・無料試用アイテム（仕様訂正後）

タイムタイム `time_thymus` は朝・昼・夜、シーズンレーズン `season_raisin` は春・夏・秋・冬を切り替えます。月変更の実装は未公開の旧復元の誤りでした。月は現実JSTの月を維持し、時間帯と季節の試用状態は独立しています。

外回りで無料試用できます。所持数・入手・価格・消費チェックは未接続と明示します。シーズンレーズンは使用日の翌日23:59:59.999まで有効、日本時間の翌々日00:00を排他的な失効境界とし、現実の季節へ戻ります。固定24時間ではありません。使用時に期限を保存し、リロード・休止復帰では延長しません。四季選択を維持し、月選択は追加しません。

タイムタイムには期限を追加せず、時間帯の試用選択を解除まで端末へ保持します。朝昼夜の自動時刻境界は未決です。季節の失効や解除でも時間帯は保持し、実日時は変えません。

公開済みの期限なし季節保存は、既存の `selectedAt` から翌々日00:00 JSTを算出し、一度保存します。移行時の現在日時からは算出しません。既に期限切れ、日時欠落/不正/未来、または保存期限が使用日と不整合なら季節上書きを解除します。他の保存キーは削除しません。明示的に再び試用する操作は新しい使用として期限を保存します。

新規キー `tenotsu_time_thymus_period_v1` と `tenotsu_season_raisin_v1` に別々の試用選択を保存します。誤った未公開復元の `tenotsu_time_thymus_v1` は読込も変換もしません。既読・ST・親愛データは削除しません。旧季節保存の currentSeason は現実季節または試用季節へ同期し、他の場所発見データは保持します。

実日時はJSTで表示し続けます。1秒更新、focus/pageshow/visibilitychangeで再確認します。端末時計を使い、サーバー時刻保証はありません。再生中の物語データ・Step・素材は時計や試用状態の更新で置き換えません。

`calendarConfig.js` の12か月接続先はすべて空です。時間帯別の事務所素材設定も空であり、勝手な素材やURLを作りません。未設定では既存素材を維持します。現在の朝昼夜は選択・保存・表示を切り替える土台であり、未割当の景色を自動生成するものではありません。月別素材は現実の月に基づき、読込開始時に物語URLを固定します。

検証:

```sh
python3 -m http.server 8021 --bind 127.0.0.1
node --test tests/*.test.cjs
TZ=America/Los_Angeles node --test tests/calendar.test.cjs
```

実機iOS Safari、多言語、本番月別接続先、全保存形式は未検証です。新規契約・課金・認証、12台のサーバー新設、端末間同期は実装しません。
