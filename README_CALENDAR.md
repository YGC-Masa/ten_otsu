# 実日時・2時間の無料試用アイテム

タイムタイム `time_thymus` は早朝・朝・昼・夕方・夜・深夜、シーズンレーズン `season_raisin` は春・夏・秋・冬を切り替えます。どちらも**実際に使用した時刻から2時間（7,200,000ms）**だけ有効で、期限ちょうどで失効します。従来の翌々日00:00 JST期限と時間帯の無期限保持は撤回済みです。現実のJST日時・月は変更しません。

無料試用・所持数/入手/価格/消費チェック未接続という既存の扱いを維持します。二つの保存状態・使用時刻・期限は独立です。既存試作で可能だった併用、明示的な再試用（新しい使用時刻から再計算）、個別解除を維持し、正式な同時使用/再使用/経済ルールを新しく確定したものではありません。

## 保存と旧データ移行

- 既存の `tenotsu_time_thymus_period_v1` と `tenotsu_season_raisin_v1` キーを維持し、レコードのversionを2へ更新します。
- 使用時に `selectedAt` と `expiresAt` をISO UTCで保存します。期限は常に `selectedAt + 2時間` であり、再読み込み・起動・休止復帰の時刻から再計算しません。
- 公開済みversion1は元の `selectedAt` から移行します。季節の旧期限がある場合は旧仕様との整合を確認し、新期限は短い2時間へ訂正。時間帯の旧期限なしデータにも元の使用時刻から期限を付けます。
- 元の使用から既に2時間以上、時刻欠落/不正/未来、または期限不整合の場合は、そのアイテムの上書きだけを解除します。移行時に2時間を付け直して延命しません。
- 既読・ST・親愛・場所/発見状態、もう一方のアイテムは削除しません。ST等の既存実経過時間による回復処理は変更しません。
- 誤った未公開復元の `tenotsu_time_thymus_v1`（月変更）は読込/変換しません。

## 時計・描画

JSTで表示し、1秒更新およびfocus/pageshow/visibilitychangeで失効を再確認します。端末時計を使用し、サーバー時刻照合は行いません。

物語の再生中は、期限や現実の日時が変わっても物語データ・Step・表示中の背景/人物素材を途中で差し替えません。物語の終了後や次回の場所表示で現実の状態を使用します。

現実の時間帯はJSTで、早朝04:00〜07:00、朝07:00〜10:00、昼10:00〜16:00、夕方16:00〜19:00、夜19:00〜23:00、深夜23:00〜翌04:00です。季節は春3〜5月、夏6〜8月、秋9〜10月、冬11〜2月です。期限切れ後はその時点の現実の時間帯・季節へ戻ります。

`calendarConfig.js` の12か月接続先および時間帯別事務所素材設定は未設定のままです。現実の月に従い、未設定は既存素材へ戻します。季節変更で参照する別月や新規サーバーを追加しません。

## 検証

```sh
python3 -m http.server 8054 --bind 127.0.0.1
node --test tests/*.test.cjs
TZ=America/Los_Angeles node --test tests/calendar.test.cjs
```

使用から2時間の直前/ちょうど/直後、月末・年越し・うるう日、時差、旧保存移行、再読み込み・各復帰イベント、独立した期限、再生中保持と既存保存の保全を確認します。店長からiOS実機で触った範囲に問題なしとの報告あり。ただし本変更の実機確認は別途で、開発側はChromiumで検証します。
