## 操作と状態

外回りの分類→場所→「ここへ移動」。画像読込成功後に背景・現在地を更新し、小さな現在地表示へ切り替える。「場所一覧」で3列へ戻り、「事務所に戻る」で帰還する。現在地は既存保存のcurrentPlaceIdに追加し、既読・親愛・ST等を削除しない。ロード失敗や古い非同期応答では現在地を変えない。

背景訪問は施設入場、施術・宿泊・乗車等のサービス利用や開催イベントの解放ではない。私宅/職員/VIP/市外交通の未定条件を解除しない。隣接、距離、方位、移動時間、料金、営業時間を追加していない。

遭遇の旧season配列は維持。マリンピア海中トンネルは夏、公園は春夏秋のみ遭遇対象。背景訪問とは独立し、冬の若葉公園背景は訪問可能だが冬の遭遇は開始しない。ST10は既存遭遇時のみで、移動に新しい消費は設けない。正本の季節適性を新たな入場ゲートにしない。

JSTの現実日時/月/季節表示は維持。既存朝昼夜の試用選択に対応画像がある場合は切替。冬の公園には正本冬素材を使用。未制作差分は代表背景として表示し、6時間帯の境界や営業時間を新設しない。再生中は日時更新で本文/Step/背景を変えない。タイムタイム/シーズンレーズンの新しい2時間仕様は本変更に含まない。

HUDはCSSの数値文字/余白のみ縮小。ST/BP値、回復、消費ロジックは変更しない。既存のアルバムPC36px仕様と未公開PC44px差分は混ぜない。

ビルド不要。Python HTTPサーバーで正本ルートを配信する。`node --test tests/*.test.cjs`、`TZ=America/Los_Angeles node --test tests/calendar.test.cjs`。追加5テストは登録の整合、画像ロード前の保存禁止、失敗/競合/再生中保持、背景訪問と遭遇条件の分離を検証。
